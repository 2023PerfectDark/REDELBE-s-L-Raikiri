Installation intructions:
To install REDELBE, copy the file "dinput8.dll" and the folder "REDELBE" in the folder where you have the game installed.
The "[Optional] Extras" folder contain extra optional functionality. Read the readme there for more info.

---------

How to install mods for REDELBE:
The proess of installing mods for REDELBE usually consist in just merging the REDELBE folder of the mod with the one of your installation.

---------

How to use mods made for REDELBE:

Mods for REDELBE come in three variants: replacer mods, new costume mods, and new hair mods:

* Replacer mods just replace some costume/hair in the game.

* New costume mods: new costume mods can be selected in the specific slot they work for (that includes the color variants), which the modder should tell you.
Once you are in the costume selection screen, press the following key/button:

XBOX controllers: the "Back" button.
PS3 controllers: the "Select" button. 
PS4 controllers: use the "Share" button. You may need a program called "DS4Windows" and ticking an option called "Hide DS4 controller" for the button to work as equivalent of the xbox back button.
Other controllers: the equivalent key to the above three.
Keyboard users: the F key.

Alternative buttons: (traverse the list in reverse order)
XBOX controller: LTrigger (pressed at more than 50%)
Playstation controllers: L2 (pressed at more than 50%)
Other controllers: whatever that is mapped as LTrigger for the xinput api.


Pressing that button/key WHILE YOU ARE CHOOSING A COSTUME will cycle through all costume mods in that costume slot.

* New hair mods: new hair mods can be selected in the specific HAIR slot they work for, which the modder shoudl tell you.
Once you are in the hair/glasses selection screen, press the following key/button:

XBOX controllers: the "Back" button.
Playstation controllers: the "Select" button.
Other controllers: the equivalent key to the above two.
Keyboard users: the F key.

Pressing that button/key WHILE YOU ARE CHOOSING A HAIR will cycle through all hair mods in that slot.
