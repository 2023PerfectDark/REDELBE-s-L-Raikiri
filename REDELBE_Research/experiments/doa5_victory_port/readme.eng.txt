## for Blender DOA5PC Motion Importer Addon

This add-on is possible to import DOA5PC Motion.



## Caution

Never fail to make a backup copy.

Not importable motions are a lot.

This version is not compatible Blender 2.7x.
I checked in Blender 2.83.7 and 2.90.1.

If you downloaded from direct url, this might be old version.
Check this url.

## How to install

1. Start Blender. "File -> User Preferences" and go "Add-ons" tab. click "Install from File...".

2. Select "io_import_doa5pc_motion.py" and click "Install from File...".

3. Check "Import-Export: Import DOA5PC Motion".

4. Click "Save User Settings".

5. This add-on appeared as "DOA5PC Motion" in "File -> Import".
