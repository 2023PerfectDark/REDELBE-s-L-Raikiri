# REDELBE-s-L-Raikiri

This is the compatible version of Dead or Alive 6 REDELBE made by vagonumero13

Add to Dead or Alive 6 Last Round game directory.

In "installation," installing REDELBE LR will install everything you need in the "REDELBE's Last Raikiri" folder and bridge the Katana mod manager and REDELBE LR. REDELBE.ini is the same as in DoA6. Most features are not implemented yet.
